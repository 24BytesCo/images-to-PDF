Tres formas de partir un PDF

Extraer un rango sirve cuando solo necesitas una parte: el capítulo de un libro, la página firmada de un contrato o el certificado que viene dentro de un paquete de documentos.

Separar cada página genera un PDF por hoja, útil para facturas o comprobantes escaneados en lote que luego hay que archivar uno por uno. Partir cada N páginas resuelve el caso de un archivo demasiado grande para un formulario que solo admite cierto número de hojas por carga.

En los tres casos las páginas se copian sin recomprimir: el resultado tiene la misma calidad y el mismo texto seleccionable que el original.

Cómo funciona

  1. Carga tu PDF. Arrástralo a la zona de carga o pulsa para elegirlo. Se muestra cuántas páginas tiene.
  2. Elige cómo dividirlo. Escribe un rango de páginas, sepáralas todas en archivos individuales o parte el documento cada N páginas.
  3. Descarga el resultado. Si es un solo PDF se descarga directo; si son varios, llegan juntos en un ZIP.

Preguntas frecuentes

¿Mi PDF se sube a algún servidor?

No. Todo el proceso ocurre en tu navegador con JavaScript. El archivo nunca se envía por internet, por eso sirve para documentos con información sensible.

¿Cómo escribo el rango de páginas?

Con números y comas, por ejemplo «1-3, 5, 8-10». Puedes mezclar páginas sueltas y rangos; si el formato no es válido o una página no existe en el documento, se avisa antes de generar nada.

¿En qué formato llegan varios archivos?

En un único ZIP con un PDF por archivo, numerados en orden, para que no tengas que descargarlos uno por uno.

¿Qué pasa si mi PDF tiene contraseña?

Se intenta abrir igual. Si el archivo está realmente protegido y no se puede leer, se avisa con claridad y no se genera nada.

¿Tiene algún costo o límite de páginas?

Es gratis y sin límite de usos. El tope real es la memoria de tu dispositivo con documentos muy grandes.

¿Cuál es la diferencia entre dividir y extraer páginas?

Extraer saca las páginas que indiques a un único PDF nuevo. Dividir parte el documento completo en varios archivos: uno por página o uno cada N páginas. Las tres opciones están en el mismo selector.

¿Puedo extraer páginas que no son consecutivas?

Sí. Escribe páginas sueltas y rangos separados por comas, por ejemplo «2, 5-7, 12». Salen en un solo PDF y en ese orden.

¿El PDF original se modifica?

No. El archivo original queda intacto en tu equipo; la herramienta crea archivos nuevos.
