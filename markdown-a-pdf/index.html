Un PDF de verdad, no una captura de pantalla

Muchos conversores de Markdown toman una foto de la vista previa y la pegan en un PDF: el resultado no se puede buscar, no se puede copiar y se ve borroso al ampliar. Aquí el documento se reconstruye elemento por elemento: los títulos son texto, las tablas son tablas y los enlaces se pueden pulsar.

Eso lo hace útil para lo que de verdad se escribe en Markdown: documentación técnica, actas, apuntes de clase, notas exportadas de Obsidian o Notion y archivos README. Puedes elegir A4 o Carta, tres anchos de margen, el tamaño de letra y si quieres número de página al pie.

Soporta títulos de seis niveles, negrita, cursiva, tachado, listas anidadas y de tareas, citas, tablas con alineación, código en línea y en bloque, reglas horizontales y enlaces. Las tildes, la ñ y los signos ¿ ¡ salen correctamente.

Cómo funciona

  1. Pega o carga tu Markdown. Escríbelo directamente, pégalo o arrastra un archivo .md, .markdown o .txt.
  2. Revisa la vista previa. Se actualiza en vivo mientras escribes, así ves el resultado antes de exportar.
  3. Descarga el PDF. Elige tamaño de página, márgenes y tipografía, y pulsa Descargar PDF. El texto queda seleccionable y buscable.

Preguntas frecuentes

¿Mi Markdown se sube a algún servidor?

No. Tanto la vista previa como la generación del PDF ocurren en tu navegador con JavaScript. El texto que escribes o el archivo que cargas nunca se envían por internet.

¿Hay límite de tamaño o de páginas?

No hay un límite fijo. Documentos de cientos de líneas generan un PDF de varias páginas sin problema; el límite real es la memoria de tu dispositivo, igual que con cualquier programa que corre en el navegador.

¿El PDF es una imagen o tiene texto real?

Tiene texto real. La herramienta no toma una captura de la vista previa: recorre tu Markdown y construye el PDF con texto seleccionable y buscable, incluidas las tablas y el código.

¿Qué pasa con las imágenes y el HTML que pego dentro del Markdown?

Las imágenes en formato data: o alojadas en el mismo origen se incluyen en el PDF; si una imagen remota falla por las restricciones de CORS del navegador, se omite y se avisa, sin interrumpir la descarga. El HTML incrustado en el Markdown se ignora en el PDF: no se interpreta ni se ejecuta.

¿Tiene algún costo o marca de agua?

Es gratis y sin límite de usos. El PDF sale limpio, sin marcas de agua ni anuncios superpuestos.

¿Puedo exportar un README.md directamente?

Sí. Arrastra el archivo .md al editor o pega su contenido. Los títulos, listas, tablas, bloques de código y enlaces del README se convierten tal cual.

¿Se ve igual que en GitHub?

Parecido, no idéntico. Se respeta la estructura de GitHub Flavored Markdown (tablas, listas de tareas, tachado), con una tipografía pensada para leer e imprimir. El HTML incrustado en el Markdown se ignora.

¿Las imágenes del Markdown salen en el PDF?

Las incrustadas como data URI sí. Las remotas dependen de que su servidor permita leerlas desde el navegador; si no lo permite, se omiten y se avisa, sin dañar el resto del documento.
